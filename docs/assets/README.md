# SessionPulse — Icon Assets

Identity assets for **SessionPulse**, conforming to the [Ninja6-MC Brand Identity System](../../brand/ICON_PLAN.md).

## Authoring Source

* [`icon-master.svg`](icon-master.svg) — **Sole authoring file.** Geometry only (no baked color, no baked background plate). `#geo` (stroke 48, dot r=54) and `#geo-small` (stroke 118, dot dropped).

All variants and PNG ladders are generated by [`scripts/export-icons.mjs`](../../scripts/export-icons.mjs). **Do not edit generated SVGs directly.**

## Generated Asset Inventory

| File | Variant | Target / Usage |
|---|---|---|
| `icon.svg`, `icon-*.png` | Variant 1 (Primary, Opaque) | Platform avatars: Modrinth, Hangar, GitHub, CurseForge |

| `icon-small-dark.svg`, `icon-small-light.svg` | Variant 4 (Small-Size Cut ≤24px) | Favicons, comment badges |
| `icon-small-plate-*.png` | Variant 4p (Small on Plate) | SpigotMC 128×128 resource slot |
| `icon-mono-dark.svg`, `icon-mono-light.svg` | Variant 5 (Monochrome) | Single-color stamps, watermarks, print |

## Re-generating Assets

To regenerate all variants and PNG sizes from `icon-master.svg`:

```bash
node scripts/export-icons.mjs
```

This runs safe-zone assertions ($R \le 460\text{px}$) and bidirectional paint assertions before emitting files.
